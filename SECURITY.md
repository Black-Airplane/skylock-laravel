# Security

Please report a vulnerability privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue for it. We'll reply within two working days and tell you when a fix is released.

Fixes go into the latest release only, so upgrade to it.

This package is designed to send SkyLock only names, statuses and numbers (see "What it sends" in the README). Anything that could make it send more, such as an error message, a host, a query, an environment value, a command argument or anything a user entered, counts as a vulnerability.
